# 📊 Digital Advertising Performance Analysis | Power BI

## 📌 Introduction

This project explores digital advertising campaign performance across industries using Microsoft Power BI. The analysis focuses on advertising expenditure, conversions, revenue, profit and Return on Ad Spend (ROAS) to understand industry-level performance and quarterly trends. 

- **Note: To download the interactive file go to 📊 [powerBI_project_portfolio folder](https://github.com/kevinpoly99/PowerBI_Project_Portfolio/blob/main/powerBI_project_portfolio.pbix) and click on 'View Raw'
- To catch a glimpse of the dashboard go to [PowerBI screenshot] (https://github.com/kevinpoly99/PowerBI_Project_Portfolio/blob/60f7fba54d74663aa2a6e185260c7f273de648e2/PowerBI%20screenshot.png)



## 🔎 What You'll Find

- Industry-level advertising performance comparisons.
- Quarterly conversion trends across 2024, 2025 and Q1 2026.
- Revenue and profit comparisons across six industries.
- Advertising expenditure and Cost Per Acquisition (CPA).
- Median ROAS comparisons across industries.

## 🎯 Project Goal

The objective was to understand which industries demonstrate stronger advertising performance and to showcase my skills and expertise on PowerBI tool.

The dashboard is intended to provide insights that could help marketing analysts and advertising agencies evaluate campaign performance and support data-informed decisions.

## 📚 Background

The analysis uses a digital advertising campaign dataset containing information across multiple industries, campaign performance metrics and financial indicators.

The dashboard was developed in Power BI while executing main features like Data Visualization and Power Query that is used to prepare the dataset by modifying data types, removing unnecessary columns and updating column headings.

## 📈 Findings

- **Industry Performance:** Finance recorded the highest revenue and profit, followed by Healthcare and SaaS. Gaming recorded the lowest financial performance.
- **Quarterly Trends:** Q4 2024 recorded the highest median conversions, reaching approximately 40. Q4 2025 also showed a noticeable increase, reaching approximately 37.
- **Advertising Investment:** Total advertising expenditure reached $18.0M, with a median CPA of $124.97.
- **ROAS:** Median Return on Ad Spend varied across industries, ranging from 1.0 to 5.3, highlighting differences in advertising returns.
